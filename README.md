# Windows XP Portfolio [View Demo](https://xpirasana.tech)

## Project Overview

This is a retro-style portfolio inspired by the **Windows XP** design. I didn't just want to make a simple website to rewrite my resume, so I decided to add a personal touch. The idea came from my first desktop OS being Windows XP when I was 6 years old, and I thought it would be fun to integrate that nostalgia into my portfolio. Right now, I’m finishing up the Windows manager tab at the bottom to make it more responsive. This is just the initial version, and I still have a lot more planned for the future!

## Why I Made It

I created this project because I didn’t want my portfolio to be just another standard website. Instead of the usual "resume-style" site, I wanted to give it a unique retro feel. The Windows XP interface holds a personal significance for me, and I thought it would be fun to recreate that experience while showcasing my work.

## Technologies Used

- **React** – Used for creating the interactive user interface.
- **npm (Node Package Manager)**: Used to manage project dependencies and install packages.
- **CSS** – Custom styling to recreate the classic Windows XP look.
- **Tailwind CSS** – CSS framework to make the actual portfolio website more responsive and ensure a clean, modern design.
- **JavaScript** – To handle the interactivity (e.g., opening files).
- **HTML** – For structuring the content and embedding the portfolio sections.
- **Git**: Used to version control the project and manage changes efficiently during development.

## Parts of the Code I’m Proud Of

- **Icon and Screenshot Research**: I’m proud of the research I did to find authentic icons and old screenshots to make the portfolio feel as close to the original Windows XP experience as possible.
- **Interactive File System**: I’m also proud of how I’ve managed to simulate an interactive file system where each "file" opens a different section and am planning to add MS Paint soon and other things.
- **Git Workflow**: I used Git to organize tasks, keeping track of what I needed to do and marking them as completed, simulating how I’d work in a real job.
- **Tailwind CSS**: I’m proud of using Tailwind CSS to design the portfolio website, a popular utility-first framework, because I wanted to gain hands-on experience with it while building this project.
- **Free Domain & Hosting**: At the last hackathon, I received a free domain name and learned to host my website using Netlify. This was a new experience for me, as I had never learned how to host a website in school. It's simple, but it’s amazing to me that a website of mine is available on the internet for everyone.
